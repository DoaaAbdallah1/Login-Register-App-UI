## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/DoaaAbdallah1/Login-Register-App-UI.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Login-Register-App-UI
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
